# MicBoost

MicBoost is a application which you can use for increase your microphone voice or noise cancellation and more!

ATTENTION! FIRST YOU HAVE TO DOWNLOAD VB CABLE FROM "**https://vb-audio.com/Cable/**"

# HOW TO USE:

1)Download zip folder and extract somewhere you want.
2)Open exe file and choose your output as VB Cable thing
3)Choose your microphone, do your settings and press the star button then you are ready!
